# Value flow (`flow FIELD`) - implementation plan

Written 2026-09-21 from his example: 'if I change a MOVE statement it could have business impact through that program or the calling-program tree - the tool cannot identify those, right?' Right. This is the plan to close that: one row per (source, target) the compiler moves data between, per-program offsets, CALL arguments matched to the callee's parameters, and a `flow` query that walks the chain and LABELS every place it widens or stops instead of following silently. It ships in the next re-parse batch (ROADMAP item 14). Produced by a three-reader, two-design, one-judge review of the working tree; every `file:line` was checked against the tree that day.

## 4. Query - `atlas/flow.py` engine; `cmd_flow` wrapper in `atlas/query.py` next to `field` (`:4162`, dispatch `:4276`)
`flow FIELD [--program P] [--up] [--hops 3] [--width 12] [--nodes 200] [--derived] [--all] [--budget CHARS]`
- Node = `(program_id, root pfield, lo, hi)`: bytes inside one 01 of one program, never a bare name (`WS-STATUS` is three unrelated fields in CONDLOGX, MULTILN, SQLCOLS; `field` merges them, `atlas/query.py:940-957`). Without `--program`: one tree per declaring program, capped at `--width` with the collapse line. Start name resolves through `field_alias` (`atlas/schema.sql:630-639`); an 88 -> its parent; ambiguous -> candidates printed with `HUMAN MUST VERIFY`, none picked.
- Step 0, overlay closure (free, printed `also read as:`): every pfield of the root whose bytes intersect `[lo,hi)` - children, parent groups, REDEFINES items (`atlas/copybook.py:412-421` keeps them at the same offset), OCCURS items (`OCCURS element, index unknown`, whole span), `after_odo` items (`offset is a maximum (ODO)`). Outgoing edges are searched for every name in the closure; the label says which name carried the value.
- Edges, fixed order (cross-program first so `--width` drops local MOVEs last); each is one hop:
  1. File: root in `file_record` with an `io_out`/`write_from` -> `file_decl.assign_dd` -> `dd` where `UPPER(dd_name)=assign_dd` (exact, then the `LIKE '%DD'` suffix of `flow_from`, `atlas/query.py:833-836`) and `step.effective_pgm` = this program -> `dsn_resolved` -> other `dd` rows on that DSN (`v_dataset_flow`, `atlas/schema.sql:471-481`; `mode` printed with `mode_source`; `is_temp` only inside the job) -> reader: (a) COBOL program -> `file_decl` by DD -> `file_record` roots -> pfields overlapping the same bytes; print the reader's `src_member` and warn `copybook differs from the writer's: verify layout` when it differs from the writer's; (b) SORT/ICETOOL/SYNCSORT: `card_field_ref` (`:487`) rows of kind INREC/OUTREC/OUTFIL for the step -> end `sort step re-arranges bytes - mapping not indexed` (the `c:` output columns are stripped, `atlas/jcl.py:1071`); else pass through to SORTOUT/OUTFIL outputs, `bytes unchanged`; (c) IEBGENER/ICEGENER with no GENERATE/RECORD cards, IDCAMS REPRO: identity (GENERATE/RECORD -> end `utility step - bytes not modelled`); (d) other utility / DB2 LOAD: end; (e) `interface_edge` on the DSN -> end `dataset leaves the mainframe (interfaces: ...)`; CICS `cics_out` via FILE -> `cics_file.dsname` (`:570`) -> same rule.
  2. CALL out: `call_arg` rows whose pfield is in the closure (or an ancestor root) -> static target or each `resolved` candidate (label `candidate: resolved via MOVE literal`; `(+N more)` or none -> end) -> `programs_named` (`atlas/query.py:161`) -> `param` with `entry` = the alias when the target matched `program_alias` (fixes `flow_from`'s `:793` gap), `pos` match -> callee bytes `[lo - arg_root_off + param_off ...)` truncated to the param's length. `content|value` -> label `BY CONTENT: one-way`; `length_of` -> end; `address_of` -> callee `set_address` rows on that param; no `param` at pos -> end `LINKAGE position out of range / count mismatch - HUMAN MUST VERIFY`; callee absent -> end. `commarea` -> `param(entry='DFHCOMMAREA')` (label `by CICS convention`), none -> end `callee has no DFHCOMMAREA 01`. `cics_return`/`cics_start` edges -> `transaction_def` (`:544`) -> program -> DFHCOMMAREA / `cics_in` RETRIEVE rows. Optional: JCL `step.parm` -> `param pos 1` of the step's program, label `PARM (halfword length + text)`.
  3. LINKAGE back: root is a `param` (or DFHCOMMAREA) of this program and the closure has a write -> every caller's `call_arg` at that pos (`_callers_of`, `:656`); `how=content|value` callers skipped with `not returned: BY CONTENT`.
  4. DB2: `sql_col_ref` write rows with `pfield_id` in the closure -> every `read` row on the same (base table, col) (`cmd_column`'s rule, `:2146`) -> one table under the node `via POLICY_TBL.STATUS_CD: n static readers, no ordering` (rows: program, host var, cite) - never n nodes; `tbl='?'` or none -> end.
  5. IMS: `dli_out` in closure -> `dli_call.dbd_name` at that line (NULL -> end `PCB unresolved`) -> every `dli_in` with the same `dbd_name` -> its I/O-area root at the same bytes; label `segment not resolved (RM-03) - matched by DBD and offset`.
  6. CICS carriers: `cics_out` -> `cics_in` with the same `(resource_kind, resource)` (`cics_cmd`, `:582-590`); TDQ also -> `cics_resource` DSN -> rule 1; map -> `screen_field` overlap -> end `screen field - a human sees it`.
  7. MQ: `mq_out` -> `mq_in` on the same queue name, else end `MQ PUT to Q (peer from manifest)`.
  8. Pointer: `set_address` (x -> p) then `set_address` (p -> a) in the same program -> `a` overlays `x`, label `pointer alias`.
  9. Copies: `data_flow.kind IN (move, move_corr, set, read_into, write_from, io_in, returning)` with `src_pfield` in the closure. Elementary -> the item, `converted PIC -> PIC` when pic/usage differ, `truncated N -> M` when shorter; group source -> `[lo - src.off + dst.off ...)` truncated to `dst.length`, then the covering elementary items of the destination root (none -> node `unnamed bytes of G (X(300))`, which still expands through its own closure); `move_corr` -> same-named immediate children recursively, FILLER/REDEFINES/OCCURS children excluded; ref-mod with two integer literals narrows, anything else widens with `(ref-mod with variable position: whole item)`; `src_sub` -> `(subscripted: any of N elements)`.
  10. Derived (`arith|string|unstring|function|inspect`): only with `--derived`, label `derived (COMPUTE)`; otherwise counted per node under "Not followed".
- `literal`, `figurative`, `initialize`, `accept` rows into a node are not edges; listed once per node as `also set here: MOVE SPACES @cite` (origins under `--up`); plus `also written by n other statements (order not checked)`.
- `--up` mirrors every rule: readers -> writers (`v_dataset_flow.mode IN (output, mod)`, none -> `no indexed writer (created outside: FTP/NDM/UNLOAD?)`), LINKAGE -> callers' args, BY REFERENCE arg -> callee's writes to the param, DB2 read -> write rows, GU -> ISRT/REPL, `cics_in` -> `cics_out`.
- Caps: `--hops` (a node at the limit prints its edge count and `hop limit N`); `--width` per node, ordered by rule then program name, surplus -> `... 188 more MOVE targets in 41 programs: CLMPOST 23, RATECALC 19, ... (--all)` naming every program (LESSONS 90); `--nodes` total; cycles: a range within a visited node of the same root prints `> X (shown as 1.1)` and stops (cuts caller/callee ping-pong); `--budget` cuts from the deepest hop up keeping end reasons (the `walk` approach). Footer, always: `Flow-insensitive: statement order and IF guards are not evaluated; a hop is a copy that CAN happen.`
- Cites: `MEMBER:line "token"` via `origin` (`atlas/query.py:63-80`; a copybook line cites the copybook, `(via COPY X)` accepted by the gate, `atlas/verify_citations.py:55-57`); token = slice of `source_line_raw` (`:154`) from the verb keyword through the carrying operand, <= 40 chars, >= `WEAK_TOKEN_CHARS` (`:64`); operand on a continuation line -> range `line-line+1` (<< `WIDE_RANGE_LINES`, `:65`); SQL hops cite `sql_stmt` start-end with the column as token; JCL hops cite `member_name:dd_line` with the DD text.
- Fallback when `sqlite_master` lacks `data_flow` (his index at work until the night): MOVE edges from `field_ref` only where a line holds exactly one `MOVE read` and one `MOVE write`; every other MOVE line counted in `N MOVE statements could not be paired (index predates data_flow)`; CALL/LINKAGE/DB2 hops from `call_edge`/`linkage_using`/`sql_col_ref`; file bytes for program-owned `field` rows only, `copybook fields: not followed until re-parse`; a LINK's COMMAREA is the callee's `01 DFHCOMMAREA` with or without PROCEDURE DIVISION USING (`callee has no DFHCOMMAREA 01` only when no such 01 is declared); a callee parameter or group node whose own name is not written (up) / used (down) but a field under it is, or whose fields come from a COPY, ends `callee's fields under the parameter: not followed until re-parse` / `fields under the group: not followed until re-parse`, never a silent drop or `no further use`; every hop `(reconstructed)`, header `index has no data_flow - reconstructed from field_ref; exact after the next re-parse`.
- Integration: `flow_from` (`atlas/query.py:773-862`, reachable only from `literal` `:1108`, untested) becomes `flow.lines_from(conn, pid, name, hops=1)`; `pack --kind field` (`:1855`) adds a `flow` section at priority 2 (`hops=2, width=8, nodes=60`); `field` prints one pointer line to `flow` in place of the caveat at `:968-969`; `diff OLD NEW` (`:3281`) runs `flow --hops 2` from the targets of every MOVE/COMPUTE/STRING/CALL on a changed line of NEW, replacing "no fact the index tracks changed" (`:3411-3413`) - the direct answer to "I changed a MOVE".
