# V01-values-list-listing - a data copybook whose 88-level VALUES list of six-digit codes runs over three lines is filed as a compiler listing

Found by the verifier of ROADMAP re-parse items 20 and 22, confirmed by the acceptance test of the batch. XQNAICS lists the NAICS construction codes as an 88-level VALUES clause over four lines; three of them hold two six-digit numbers each, the shape the classifier took for a compiler listing's numbered source lines (the listing's line number, then the record's own sequence number). Truth: a copybook, expanded into XQPGM01. Tool: `listing`, and XQPGM01 `partial - COPY XQNAICS NOT FOUND` with the member on disk.

Fixed in LESSONS 248: the numbered lines must be the listing's own - each line number the one before it plus one, as the compiler numbers every line it prints.
