# V03-doc-heading-level - a prose heading such as 02 Premium values files a document as a copybook

Found by the verifier of ROADMAP re-parse items 20 and 22, confirmed by the acceptance test (minor). The heading `02 Premium values` starts in column 1 with a level-like number, a word and the word VALUES - the column-1 form of the data-entry signature, which needed only a clause's keyword.

Fixed in LESSONS 248: the column-1 form, and every data entry in a library of documents, needs the clause with its operand (a picture string, a literal, a number, a name).
